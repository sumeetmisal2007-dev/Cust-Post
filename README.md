# Cust-Post 🌱

> **Space-Aware, Evidence-First Composting Assistant for Urban Beginners**

Cust-Post empowers apartment dwellers, students, and urban families to divert household organic waste into nutrient-rich compost within tight space constraints (balconies, utility corridors, terraces).

Built in direct alignment with **United Nations Sustainable Development Goal 12 (Target 12.5)**.

---

## 🏛️ Core Architecture & Guardrails

1. **Zero Unverified AI Verdicts:** All safety-critical guidance, container clearances, volume calculations, and troubleshooting resolutions are generated by deterministic rule engines backed by open municipal and agronomic literature (US EPA, MCGM, ADEQ, FAO).
2. **Honest Uncertainty:** Containers with unknown chemical history or incomplete user inputs trigger `more_info_needed` rather than falsely defaulting to "safe".
3. **Geometric Volume $\neq$ Biological Capacity:** Live container dimension calculations ($L \times W \times H \div 1000 = \text{L}$) carry explicit disclaimers separating physical vessel volume from biological loading rates.
4. **Physical Maturity Gate:** Compost is never declared ready by calendar time alone. Batches require explicit confirmation of a 4-point observable checklist (color/texture, earthy odor, ambient temperature, unrecognizable scraps) before completion.
5. **Transparent Data Status:** Every recorded metric explicitly carries a visual status badge (`measured`, `estimated`, `user_reported`, `unknown`).
6. **Privacy First:** No mandatory accounts for planning or tracking; anonymous guest browser storage; zero GPS geolocation tracking; 1-click hard cascade data erasure.

## 🛠️ Tech Stack

- **Framework:** [Next.js 15 App Router](https://nextjs.org/) (TypeScript, React 19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with warm paper editorial design tokens (`#009775`, `#00664F`, `#F6B73E`, `#F8F3E9`, `#FFFDF8`, `#17372E`)
- **UI Primitives:** Radix UI Slots, Lucide Icons, Class Variance Authority
- **Database & Auth:** [Supabase](https://supabase.com/) PostgreSQL with Row-Level Security (RLS) & `@supabase/ssr` (with fallback local storage adapter for anonymous guests)
- **State & Forms:** Zustand, React Hook Form, Zod
- **Testing:** Vitest (unit & integration) + Playwright (end-to-end browser journeys & axe-core WCAG 2.2 AA accessibility)

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Installation

```bash
# Clone the repository
git clone https://github.com/sumeetmisal2007-dev/Cust-Post.git
cd Cust-Post

# Install monorepo dependencies
npm install

# Set up environment variables
cp .env.example .env.local
```

### Development Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
